# 中心声像高度 · 0.4.0

中心高度的源码、数据来源检查、离线音频、原生界面与真实设备链路验证已完成。2026-10-30 交付 **0.4.0 build 4**，应用保持运行；本页将数字处理、设备流量与本人听觉定位评价分别记录，不把实机流量当作本人已听测。

## 操作与界面

- 左侧“中置信号 / 中心”增加“中心高度”滑杆，范围 −45° 至 +45°，0° 为原高度，正值向上、负值向下。
- 底部原“中心声像”旋钮改为“中心高度”，与左侧高度滑杆双向同步；左右声像保留为左侧滑杆，不再占用底部旋钮。
- 高度同时改变 Mid 音频和紫色中心的竖直位置。其他彩色层与场景原点不移动。界面的 Z 轴高度语义映射到绘制器的竖向坐标。
- 双击高度旋钮恢复 0°。0° 显式走原编译分支，严格保留旧声音；关闭“中心塑形”会旁路左右声像、高度和电平。

Mid 是左右声道共有的信号，并非识别或分离出的人声；所有位于 Mid 的内容都会受影响。角度表示处理所用的仰角参考，不能直接当作本人听感或实际房间位置的测量结果。

## 音频处理

对于与内置水平 HRIR 按实际系数匹配的同一供体，中心分支使用目标仰角的实测／插值 HRIR，Side 继续使用原水平 HRIR：`目标高度 HRIR × Mid + 原水平 HRIR × Side`。新中心路径不会再通过原水平 HRTF 卷积一次。

对于旁路或无法核对供体的自定义矩阵，中心分支使用选定供体的目标／水平响应生成相对高度频谱线索，以正则化、最小相位 FIR 处理原 Mid 路径；不把完整供体 HRTF 盲叠到未知矩阵上。这种模式会真实改变音频，但不宣称未知 HRTF／BRIR 上具有精确的绝对仰角。

高度阶段保持原 Side 路径；这一保持发生在整个系统共同的安全／响度增益之前。最终共同增益或末端峰值保护仍可能改变整体输出。原有常驻音量平衡读取的是已经包含高度的完整四路 FIR，无需额外开关。

七套数据各含 −50° 至 +50°、每 10° 一层的 11 个仰角节点，每层四路径，共 **308 个 48 kHz、418 样本的单声道 Float32 WAV**。用户控制限于 ±45°，位于实测节点覆盖范围内。数据选取左右 ±30° 源方向；缺少精确方位角的位置按同一仰角环的测量做明确记录的系数插值，运行时再对相邻仰角节点插值。未对左右耳分别归一化，也未独立平移脉冲起点。

[Data-Import.json](Data-Import.json) 记录源 SOFA 的路径、尺寸及 SHA256。[Independent-Bank-Verification.json](Independent-Bank-Verification.json) 独立从 SOFA 重建全部节点并逐样本检查 308 个 WAV：Float32 舍入后系数全部一致，28 个 0° 文件与既有水平基线逐字节相同。它验证数据与来源，不代表运行时 DSP 或个人定位效果已通过听测。

这些是供体测量，不是本人的耳朵测量；本人匹配、高度感知和定位收益均未验证。原始署名与衍生处理记录保存在内置数据的 `ATTRIBUTION.txt` 和 `manifest.json`。

## 已完成的验证

- [Tests.log](Tests.log)：55 项测试、8 个测试套件通过，覆盖零高度兼容、配置读写、Mid／Side 路由、供体匹配、极限参数、采样率和导出重开。新增实机发现的归零回归：原生滑杆步进可留下约 7.1e−15° 尾差，状态层将小于 1e−9° 的尾差归为精确 0°；原来的零高度 FIR 因此可严格恢复。
- [Offline-Verification.json](Offline-Verification.json)：20 组预设与 HRTF 高度组合，通过真实 CamillaDSP 4.1.3 的 RawFile 链路运行。指定相关粉红声参考的 K 加权增益最大校准误差为 **0.0005671 dB**；满幅瞬态／反相信号均受末端上限保护，精确静音输出仍为零。此误差属于该参考信号的数字校准，不是任意音乐的主观响度误差。
- [Independent-DSP-Verification.json](Independent-DSP-Verification.json)：独立静态审查及 NumPy 数学参考计算核对分支代数、Side 保持、零高度原分支、最小相位重建和采样率转换；该报告未调用 Swift DSP，也未播放音频。界面提供的 44.1／48／96 kHz 未发现所检查的失败项。

独立检查还记录了实现边界：相对高度滤波器的 **−18／+12 dB 是频谱设计目标，不是最终有限长度 FIR 的严格频谱增益上限**。矩形截断和直流修正后的最坏目标逼近误差约 **0.402 dB**；扫描中最终增益范围可超出设计目标。最终系统峰值由后续安全处理及实时末端保护另行限制，不能用这组设计目标冒充削波保证。

CLI 接受的 8 kHz 非界面采样率端点另有已知转换裁剪误差：低通插值支撑超出既有源端补零范围，输出裁剪会丢弃部分前后振铃；独立记录中的最大直流和差约 0.02974。界面的 44.1／48／96 kHz 未受到这一级别的端点损失。细节见独立 DSP 报告。

## 配置与导出

`center_imaging` 新增可选的 `elevation_degrees` 与 `height_profile`。旧配置缺省高度时保留原路径；非零高度会写入最终四路 FIR，因此应用内离线 WAV 渲染和导出的 LL／LR／RL／RR WAV 已包含高度处理。

非零高度的导出包还包含 `center-height-provenance.json`、`CENTER-HEIGHT-ATTRIBUTION.txt`，记录所用供体、仰角、处理策略、数据版本及 CC BY 4.0 来源。最终 WAV 可直接用于相应卷积链；重开配置继续编辑则需要 **FieldWeave 0.4 或更新版本及相同内置高度数据版本**。导出包不额外复制完整内置高度数据集，不能宣称它可在缺少该数据版本的旧应用中重新编译。
